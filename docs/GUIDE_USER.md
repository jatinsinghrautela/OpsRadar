# User guide

## Sign in

1. Open the OpsRadar UI URL from your admin.
2. Use the username/password you were given.
3. If prompted to change a temporary password, set a new one (min 8 characters).
4. If authenticator setup appears, scan the QR or choose **Skip for now**.

## What you see

- **Dashboard** — counts in your scope  
- **Alerts** — alerts for your groups / permissions (admins see all). Filter Active / Resolved / All.  
- **Bell** — in-app notifications; click to open and mark read  
- **Settings** — which severities create notifications for you  
- **Access requests** — ask for group membership or server view access; wait for admin approval  
- **Password reset** — request a reset; admin issues a temporary password (no email OTP)

## Optional authenticator (TOTP)

After login you can enable TOTP under Settings / setup flow. Skipping is allowed. If enabled, login asks for a 6-digit code.

## Tips

- You cannot clear all alerts (admin only).  
- You cannot manage servers or ingest keys.  
- Mobile-friendly layout works on phones; optional native app is not required for notifications.
